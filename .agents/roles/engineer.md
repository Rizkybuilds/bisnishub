# Engineer

Use for implementing an authorized MGBOS slice. Read the [workflow](../../systems/mgbos/docs/engineering/agent-system/workflow.md) and the specialist skill for the affected layer; do not load all skills by default.

Inputs: accepted scope, base revision, isolated worktree, risk classification and canonical sources. Audit dirty files before edits. If the plan is absent for a small task, record a proportionate scope and acceptance criteria before implementing.

May edit scoped files and execute safe local checks. Preserve public package boundaries, Next.js server command authorization, integer money, independent state machines, immutable history, idempotency and transactional effects. New schema corrections use new migrations. No bypass through UI, AI, n8n or service credentials.

Stop the affected path when source contracts disagree, required environment is unavailable, or a money/access/data-loss defect is found. Continue independent authorized work; report the blocker instead of silently reducing acceptance criteria.

Handoff to Auditor and QA: exact revision (or base plus dirty diff), changed files, rationale, checks and failures, risks and recovery notes. Do not self-certify independent review. Role permissions never authorize deployment, remote databases or main pushes.

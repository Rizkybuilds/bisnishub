# 1. Purpose

Affiliate Program menjawab:

> **Bagaimana pihak eksternal dapat membantu membawa demand ke TeeStock dan memperoleh kompensasi hanya ketika kontribusinya menghasilkan outcome komersial yang valid?**

Canonical principle:

> **Reward measurable contribution.**

---

# 2. Canonical Definition

> **TeeStock Affiliate Program adalah performance-based referral program yang memberikan commission kepada approved participants atas eligible transactions atau qualified commercial outcomes yang dapat diatribusikan secara valid melalui approved tracking mechanisms.**

---

# 3. Affiliate Program Is Not Reseller Program

Critical distinction:

```text id="aff001"
AFFILIATE
sends or influences demand.

RESELLER
buys / resells product.
```

Affiliate tidak perlu:

- membeli inventory,
- menentukan resale price,
- menangani customer order.

---

# 4. Affiliate Program Is Not Creator Royalty

Canonical:

```text id="aff002"
ROYALTY
compensates IP usage.

AFFILIATE COMMISSION
compensates attributed performance.
```

Seorang creator dapat menerima keduanya jika rules memang mengizinkan.

---

# 5. Affiliate Program Is Not General Discount Program

Discount code mungkin digunakan sebagai attribution tool.

Tetapi tujuan Program adalah:

```text id="aff003"
INCREMENTAL CUSTOMER ACQUISITION
```

bukan membagikan diskon tanpa attribution economics.

---

# 64. Incrementality

# 171. Affiliate Program Failure Modes

## Pay for Clicks Without Value

Fraud and bad traffic.

## Vague Attribution

Payout disputes.

## Commission on Refunded Orders

Economic leakage.

## Self-Referral Abuse

Fake acquisition.

## Coupon Leakage

Paying for organic demand.

## Mass Enrollment Too Early

Operational noise.

## All Products Same Commission

Ignores economics.

## Creator Royalty + Affiliate Accidentally Double-Stacked

Margin failure.

---

# 172. What Affiliate Program Must Not Become

## Coupon Spam Network

Performance and brand quality matter.

## Uncontrolled Influencer Spend

Compensation must remain attributable.

## Pyramid Recruitment Scheme

Commission should derive from eligible customer outcomes, not recruiting more affiliates.

## Tracking Black Box

Participants deserve understandable attribution.

## Margin Leakage Engine

Incremental contribution matters.

# TeeStock Brand Identity System v1.0

> **Canonical Visual Identity Framework**  
> Dokumen ini mendefinisikan bagaimana TeeStock harus terlihat secara konsisten di seluruh Commerce, Services, Programs, digital product, packaging, operational communication, dan hubungan dengan TeeStock Originals.

Dokumen ini mengatur **sistem**, bukan sekadar logo.

---

# 1. Purpose

Brand Identity System menjawab:

- bagaimana TeeStock tampil secara visual,
- apa karakter visual utamanya,
- bagaimana logo digunakan,
- bagaimana typography, color, imagery, iconography, spacing, dan layout bekerja,
- bagaimana master brand berbeda dari Originals,
- bagaimana visual dapat fleksibel tanpa kehilangan consistency,
- dan bagaimana seluruh touchpoint tetap terlihat sebagai bagian dari ecosystem yang sama.

Core principle:

> **Consistency without sameness.**

---

# 2. Visual Identity Objective

Visual TeeStock harus menyampaikan:

```text
CLARITY
+
TASTE
+
UTILITY
+
CONFIDENCE
```

Sistem visual tidak boleh terasa:

- terlalu fashion-editorial sehingga Services terlihat tidak praktis,
- terlalu corporate sehingga Commerce kehilangan taste,
- terlalu playful sehingga B2B kehilangan trust,
- atau terlalu technical sehingga consumer merasa jauh.

---

# 3. Desired Visual Character

Canonical visual character:

```text
MODERN
CLEAN
STRUCTURED
HUMAN
TACTILE
FUNCTIONAL
```

TeeStock harus terasa seperti brand yang:

> tahu apa yang dilakukan, tetapi tidak perlu berteriak.

---

# 4. Visual Positioning

TeeStock berada di antara:

```text
EDITORIAL FASHION
        ↕
PRODUCT SYSTEM
        ↕
MODERN COMMERCE
```

Bukan:

```text
STREETWEAR HYPE ONLY
```

dan bukan:

```text
GENERIC CORPORATE SAAS
```

---

# 5. Visual System Philosophy

TeeStock menggunakan pendekatan:

> **Neutral Core + Expressive Product Layer**

Artinya:

Master brand menggunakan sistem visual yang relatif tenang.

Product, collaboration, campaign, dan Originals boleh lebih ekspresif.

Structure:

```text
MASTER BRAND
Neutral
Stable
Recognizable

↓

PRODUCT / CAMPAIGN
Flexible
Expressive

↓

ORIGINALS / LABELS
Highly Distinct
```

# 7. Master Identity

Master identity terdiri dari:

- wordmark,
- symbol jika digunakan,
- typography,
- neutral palette,
- accent system,
- layout system,
- photography principles,
- iconography,
- motion principles.

Master identity adalah source of visual trust.

---

# 8. Logo Architecture

TeeStock harus mempunyai minimal:

```text
PRIMARY WORDMARK

SECONDARY MARK

COMPACT MARK
```

Tidak semua harus digunakan bersamaan.

---

# 9. Primary Wordmark

Primary representation:

> **TeeStock**

Wordmark harus:

- mudah dibaca,
- bekerja pada ukuran kecil,
- tidak bergantung pada trend visual,
- dapat digunakan pada digital maupun physical product.

Gunakan primary wordmark pada:

- website header,
- packaging,
- invoices,
- documents,
- storefront,
- formal communication.

---

# 10. Secondary Mark

Secondary Mark dapat berupa:

- monogram,
- symbol,
- simplified mark.

Fungsi:

```text
APP ICON
SOCIAL AVATAR
GARMENT DETAIL
FAVICON
SMALL PACKAGING
```

Secondary Mark tidak boleh menggantikan wordmark pada situasi yang membutuhkan brand clarity.

---

# 11. Logo Clear Space

Logo harus selalu memiliki breathing room.

Minimum clear space menggunakan internal unit:

```text
X = height reference from TeeStock wordmark
```

Area di sekitar logo minimal:

```text
0.5X
```

dan ideal:

```text
1X
```

Exact production specification harus diturunkan dari final artwork.

---

# 12. Minimum Size

Logo tidak boleh digunakan pada ukuran di mana:

- letterform tidak terbaca,
- detail symbol hilang,
- recognition menurun.

Untuk aplikasi sangat kecil gunakan Compact Mark.

---

# 13. Logo Misuse

Dilarang:

- stretch,
- skew,
- outline sembarangan,
- gradient tanpa sistem,
- drop shadow dekoratif,
- random recolor,
- menambahkan ornament,
- mengubah spacing manual.

---

# 14. Co-Branding

Untuk collaboration:

```text
TEESTOCK × CREATOR
```

Kedua identitas harus memiliki visual weight yang seimbang berdasarkan agreement.

Untuk Originals Label:

```text
LABEL
A TEESTOCK ORIGINAL
```

Label menjadi dominant identity.

---

# 15. Typography Philosophy

Typography TeeStock harus:

```text
CLEAR
NEUTRAL
MODERN
HIGHLY LEGIBLE
```

Gunakan typography untuk menciptakan hierarchy, bukan decoration berlebihan.

---

# 16. Typography Roles

Canonical roles:

```text
DISPLAY
HEADLINE
BODY
LABEL
DATA / TECHNICAL
```

---

# 17. Display Type

Digunakan untuk:

- campaign headline,
- homepage hero,
- major brand statement.

Karakter:

- strong,
- clean,
- distinctive enough,
- tidak theatrical.

---

# 18. Headline Type

Digunakan untuk:

- section titles,
- product titles,
- service pages.

Prioritas:

> readability sebelum personality.

---

# 19. Body Type

Harus optimal untuk:

- ecommerce,
- long copy,
- operational content,
- mobile.

Requirements:

- good x-height,
- strong readability,
- multiple weights,
- stable numeral system.

---

# 20. Technical / Data Type

Untuk:

- SKU,
- pricing tables,
- production data,
- labels,
- operational interfaces.

Boleh menggunakan:

- tabular numerals,
- monospace secondary type

jika meningkatkan clarity.

---

# 21. Typography Hierarchy

Example canonical hierarchy:

```text
DISPLAY
↓
H1
↓
H2
↓
H3
↓
BODY
↓
CAPTION / LABEL
```

Hierarchy harus muncul dari kombinasi:

- size,
- weight,
- spacing,
- position.

Bukan dari terlalu banyak jenis font.

---

# 22. Typeface Count

Master brand idealnya menggunakan:

```text
1 PRIMARY FAMILY
+
OPTIONAL 1 SECONDARY FAMILY
```

Jangan menggunakan terlalu banyak typefaces.

Independent Labels boleh memiliki system berbeda.

---

# 23. Color Philosophy

Master TeeStock menggunakan:

> **Neutral-dominant color system.**

Purpose:

- memberi ruang bagi product photography,
- membuat artwork menjadi focus,
- menjaga flexibility antar business line.

---

Canonical roles:

```text

PAPER
Primary light

NEUTRAL

SIGNAL
Primary accent

STATUS
Operational semantic colors
```

# 25. Ink

Digunakan untuk:

- primary text,
- logo,
- high-contrast elements.

Harus mendekati dark neutral.

Tidak harus pure black pada semua implementation.

# 26. Paper

Primary background.

Karakter:

- warm atau neutral white,
- nyaman dilihat,
- tidak sterile.

# 27. Neutral Scale

Diperlukan minimal:

```text
N50
N100
N200
N400
N600
N800
N900
```

Untuk:

- background,
- border,
- disabled state,
- secondary text.

---

# 28. Signal Color

Satu primary accent digunakan untuk:

- CTA,
- interactive highlight,
- key information,
- selected state.

Signal color tidak boleh mendominasi seluruh interface.

Principle:

> **Accent means something.**

---

# 29. Semantic Colors

Digunakan secara functional:

```text
SUCCESS
WARNING
ERROR
INFO
```

Tidak digunakan sebagai decorative palette.

---

# 30. Color Accessibility

Digital implementation harus menjaga:

- readable contrast,
- visible CTA,
- accessible state differentiation.

Color tidak boleh menjadi satu-satunya indicator state.

---

# 31. Product Color Dominance

Jika product/artwork memiliki warna kuat:

> master UI harus mundur.

Contoh:

```text
Neutral interface
+
Strong product image
```

lebih disukai daripada:

```text
Strong interface color
+
Strong artwork
+
Strong campaign decoration
```

yang menciptakan visual noise.

---

# 32. Layout Philosophy

Canonical layout:

```text
GRID
SPACE
HIERARCHY
```

TeeStock harus terlihat structured.

Bukan crowded.

---

Recommended conceptual grid:

```text
4 columns

8 columns
```

Implementation dapat menyesuaikan.

```text

8
12

48
64
96
```

Exact tokens dapat diterjemahkan ke CSS design tokens.

# 35. Density

Commerce:

```text
MEDIUM DENSITY
```

Editorial campaign:

```text
LOWER DENSITY
MORE SPACE
```

Admin/internal tools:

```text
HIGHER DENSITY
```

Visual character tetap konsisten melalui typography dan spacing logic.

# 36. Shape Language

Default:

- simple geometry,
- restrained border radius,
- minimal decorative shape.

Avoid:

- excessive floating blobs,
- random gradients,
- overly rounded SaaS aesthetic.

---

# 37. Border System

Border digunakan untuk:

- structure,
- grouping,
- product cards,
- data.

Karakter:

```text
THIN
SUBTLE
FUNCTIONAL
```

# 38. Photography Philosophy

Photography adalah bagian penting dari TeeStock.

Primary photography categories:

```text
PRODUCT
DETAIL
HUMAN
PROCESS
CONTEXT
```

# 39. Product Photography

Harus menunjukkan product sejelas mungkin.

Minimum desirable set:


# 40. Detail Photography

Digunakan untuk membuktikan:

- texture,
- print,
- stitching,
- collar,
- finishing.

Purpose:

---

# 41. Human Photography

Harus terasa:

- natural,
- contemporary,
- believable.

Avoid:

- overly artificial stock-photo expression,
- luxury-fashion pose jika tidak sesuai context.

---

# 42. Process Photography

Show:

- printing,
- QC,
- packing,
- sourcing,
- studio.

Membangun trust melalui:

```text
SHOW > CLAIM
```

---

# 43. Background Philosophy

Gunakan:

- simple environment,
- workshop,
- urban everyday setting,
- controlled studio.

Product dan manusia tetap menjadi subject.

---

# 44. Image Treatment

Master TeeStock sebaiknya tidak bergantung pada heavy filters.

Preferred:

```text
REALISTIC COLOR
CLEAN CONTRAST
CONSISTENT EXPOSURE
```

Originals dapat menggunakan treatment lebih ekspresif.

---

# 45. Video Identity

Video harus menggunakan:

- clean title cards,
- readable typography,
- minimal transition,
- real product/process shots.

Avoid gimmick-heavy editing sebagai default brand language.

---

# 46. Iconography

Icon system harus:

```text
SIMPLE
CONSISTENT
FUNCTIONAL
```

Gunakan satu visual family.

Jangan mencampur:

- outline,
- filled,
- illustration icons

tanpa aturan.

---

# 47. Illustration

Illustration bukan core master-brand device.

Boleh digunakan untuk:

- education,
- explainers,
- campaign,
- Originals.

Harus memiliki reason.

---

# 48. Graphic Devices

Master brand dapat menggunakan beberapa recurring device:

```text
GRID
PRODUCT LABELS
ID TAGS
INDEX NUMBERS
TECHNICAL ANNOTATIONS
```

Ini dapat menciptakan hubungan dengan:

- production,
- inventory,
- apparel construction.

---

# 49. Data-Inspired Visual Language

Karena TeeStock adalah operating ecosystem, visual system boleh menggunakan subtle references seperti:

```text
SKU

MATERIAL
FIT
BATCH
DROP
```

Contoh:

```text

RELAXED FIT
```

Namun jangan membuat consumer experience terasa seperti ERP.


# 52. Button Hierarchy

Canonical:


CTA harus actionable.

Preferred:



Product card harus memprioritaskan:

2. product/design name,
3. price,
4. relevant attribute,
5. availability jika penting.

Jangan memasukkan terlalu banyak metadata.

# 58. Base Packaging

Simple.

# 63. Garment Label System

```text

SIZE
MATERIAL
CARE

```

Operational traceability tetap tersedia melalui SKU/batch data.

---

# 64. Hangtag System

Tidak wajib untuk semua products.

Gunakan jika memberi value:

- product story,
- care,
- provenance,
- collection context.

Avoid hangtags hanya untuk terlihat premium.

---

# 65. Documentation Identity

Internal/external documents seperti:

- proposal,
- quotation,
- invoice,
- presentation,
- specification

harus memakai shared:

- typography,
- logo,
- spacing,
- table style.

---

# 66. B2B Visual Tone

TeeStock Business, Supply, dan Fulfill menggunakan versi brand yang lebih restrained.

More:

```text
DATA
CLARITY
PROCESS
```

Less:

```text
EDITORIAL DECORATION
```

Namun tetap recognizable sebagai TeeStock.

---

# 67. Social Media Identity

Social content tidak harus memakai template identik setiap post.

Consistency berasal dari:

- typography,
- photography,
- layout discipline,
- tone.

Avoid feed yang terlihat seperti kumpulan poster template.

---

# 68. Social Content Modes

Recommended:

```text
PRODUCT
EDUCATION
PROCESS
PEOPLE
EDITORIAL
CAMPAIGN
```

Masing-masing dapat mempunyai layout berbeda.

---

# 69. Campaign Flexibility

Campaign boleh menggunakan:

- temporary accent color,
- custom display typography,
- graphic device,
- image treatment.

Namun master identity tetap dikenali melalui:

- logo,
- core typography,
- layout logic,
- TeeStock presence.

---

# 70. Originals Identity

TeeStock Originals berada satu langkah lebih ekspresif dibanding master brand.

Potential characteristics:

```text

EXPERIMENTAL
CULTURAL
DESIGN-LED
```

Tetapi tidak boleh terlihat seperti company terpisah.

---

# 71. Originals Collection Identity

Setiap collection dapat memiliki:

- temporary palette,
- graphic language,
- campaign typography,
- creative direction.

Lifecycle berakhir bersama Collection jika tidak dipromosikan.

# 72. Independent Label Identity

```text

OWN COLORS

```

dan tetap menggunakan TeeStock infrastructure.

# 73. Endorsement Lockup

Early label:

```text
[LABEL LOGO]

```

Endorsement harus jelas tetapi subordinate.

---

# 74. Visual Independence Rule

Semakin mature label:

```text
LABEL VISIBILITY ↑
TEEStock VISIBILITY ↓
```

Tetapi legal, backend, dan operational relationship tidak harus berubah.

---

# 75. Cross-Brand Visual Discipline

Shared base garment tidak berarti semua Label harus terlihat sama.

Differentiate melalui:

- graphics,
- photography,
- typography,
- storytelling,
- styling.

Bukan dengan membuat backend terpisah.

---

# 76. Accessibility

Identity harus bekerja untuk:

- mobile,
- low-resolution display,
- small packaging,
- printed invoice,
- monochrome output.

Brand tidak boleh bergantung pada ideal presentation saja.

---

# 77. Print Compatibility

Logo dan core graphic system harus memiliki:

```text
FULL COLOR
ONE COLOR
REVERSED
BLACK
WHITE
```

variants.

---

# 78. Production Compatibility

Identity harus mempertimbangkan actual production methods.

Jangan membuat design system yang:

- sulit dicetak,
- terlalu mahal,
- inconsistent.

Brand design harus memahami manufacturing.

---

# 79. Sustainability Principle

Visual identity tidak boleh membutuhkan:

- excessive packaging,
- unnecessary print layers,
- decorative material waste

hanya untuk menunjukkan premium perception.

---

# 80. Design Token Architecture

Digital implementation sebaiknya memakai canonical tokens:

```text
color.*
type.*
space.*
radius.*
border.*
shadow.*
motion.*
breakpoint.*
```

Example:

```text
color.background.primary
color.text.primary
color.action.primary

space.1
space.2
space.3
```

---

# 81. Source of Truth for Tokens

Exact implementation values harus disimpan pada:

```text
design-tokens
```

atau equivalent design-system source.

Dokumen ini menentukan role dan governance.

Code menentukan implementation.

---

# 82. Asset Governance

Brand assets harus mempunyai canonical repository location.

Recommended:

```text
brand/
└── assets/
    ├── logo/
    ├── marks/
    ├── icons/
    ├── templates/
    └── guidelines/
```

Jangan menyimpan random copies sebagai final source.

---

# 83. File Naming

Recommended pattern:

```text
teestock-logo-primary-dark.svg
teestock-logo-primary-light.svg
teestock-mark-dark.svg
```

Avoid:

```text
logo-final-final2-new.svg
```

---

# 84. Version Control

Major identity change harus memiliki version.

Example:

```text
TeeStock Identity 1.0
TeeStock Identity 1.1
TeeStock Identity 2.0
```

Asset update kecil tidak selalu memerlukan strategic version bump.

---

# 85. Identity Change Threshold

Tidak perlu rebrand hanya karena:

- warna terasa bosan,
- trend berubah,
- competitor mengganti logo.

Identity change besar hanya jika:

- strategy berubah,
- brand perception bermasalah,
- system tidak lagi functional.

---

# 86. Visual Trend Policy

TeeStock boleh mengikuti contemporary aesthetic.

Tetapi:

> trend adalah layer, bukan foundation.

Foundation harus bertahan lebih lama.

---

# 87. Identity Evaluation Framework

Sebelum visual baru diapprove, tanyakan:

```text
IS IT CLEAR?

IS IT DISTINCT ENOUGH?

IS IT FLEXIBLE?

DOES IT WORK SMALL?

DOES IT WORK IN PRINT?

DOES IT WORK WITH PRODUCT ARTWORK?

DOES IT FEEL LIKE TEESTOCK?
```

---

# 88. Visual Anti-Patterns

Avoid:

## Fashion Cosplay

Membuat brand terlihat high-fashion hanya karena estetika sedang trend.

## SaaS Generic

Semua tampak seperti software startup.

## Template Dependency

Setiap desain terlihat berasal dari template yang sama.

## Excessive Effects

Gradient, blur, glow, shadow tanpa fungsi.

## Visual Overbranding

Logo muncul terlalu sering.

## Design Before Information

Estetika membuat informasi sulit dipahami.

# Arsip pengetahuan bisnis TeeStock

Materi brand, keuangan, marketing, operasional, riset, referensi katalog dan
HTML perencanaan lama dipertahankan di sini. Blueprint aktif berada di folder
bernomor pada direktori induk. Catatan sesi September 27 tetap di `catatan/sesi/`.

Implementasi storefront, shared code dan SQL historis telah dipisahkan ke
[arsip runtime](../../../archive/teestock-v1/README.md). Admin lama dihapus
oleh owner pada commit `05e8b18`. Tidak ada runtime aktif atau migration chain
MGBOS di folder bisnis ini. Tidak ada database remote yang diubah.

☁️ Database Cloud (Supabase Multi-Tenant)

Status Koneksi Cloud: 🔌 Terputus (Mode Lokal)

Hubungkan ke proyek Supabase business-hub kamu. Skema menggunakan prefix tabel ts_ untuk TeeStock, sehingga 1 akun Supabase bisa dipakai bersama dengan MultiGraph (mg_) dan Titik Buta (tb_) tanpa bentrok.

Ditemukan di: Supabase Dashboard > Project Settings > API > Project URL
Ditemukan di: Supabase Dashboard > Project Settings > API > Project API keys (anon / public)
💡 Panduan Setup 3 Menit:
1. Buat project baru di Supabase.com (region Singapore).
2. Buka menu SQL Editor > Copy & Paste isi file bisnis/teestock/database/schema.sql > Klik Run.
3. Masukkan URL dan anon Key di atas lalu klik tombol Simpan & Sambungkan.

# Modular monolith

Date: 2026-09-23
Status: ACCEPTED

## Context

Decision already established by MGBOS 0.4, 0.5.3 and 0.5.4; see the source index.

## Decision

Keep domain boundaries in one deployable application; use package exports and domain commands.

## Alternatives and consequences

Microservices add distributed operations before there is a demonstrated need.

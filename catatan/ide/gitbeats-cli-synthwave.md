# 🎵 GitBeats

> [!abstract] **Konsep Ide**
> Sebuah interactive CLI tool yang mem-parsing commit history Git repository lokal dan mengubahnya menjadi *custom procedural synthwave soundtrack* secara dinamis.

---

## 🚀 Fitur & Kemampuan Utama

* **Git Log Parser:** Mem-parsing log commit Git lokal untuk mengekstrak metadata seperti frekuensi commit, waktu kerja (jam pagi/malam), serta jumlah baris kode yang ditambah atau dihapus.
* **Music Parameter Mapping:** Memetakan atribut commit ke parameter musik prosedural, termasuk tempo (BPM), scale keys, variasi instrumen synthesizer, dan pola drum synthwave.
* **Audio Renderer & Exporter:** Merender dan mengekspor soundtrack yang dihasilkan ke format file audio MIDI dan WAV yang dapat langsung diputar.
* **Terminal ASCII Visualizer:** Menyediakan visualizer audio ASCII *real-time* di dalam terminal yang bergerak mengikuti irama musik saat pemutaran.
